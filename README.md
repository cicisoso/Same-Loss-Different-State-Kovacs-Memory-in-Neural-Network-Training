# Same Loss, Different State: Kovacs Memory in Neural-Network Training

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.23666872.svg)](https://doi.org/10.5281/zenodo.23666872)

Code and data for the manuscript *Same Loss, Different State: Kovacs Memory in Neural-Network Training* by Hao Liu,
Xiaojie Zong, Jie Chen, Jianyu Xiong, Qiao Ke, Nan Li, Xiaofeng Luo and Yi-Cheng Zhang.

A network is trained at a high learning rate, then at a low one until its held-out loss equals that of an untouched
reference, and is then trained exactly like the reference, on the same minibatches. This is Kovacs's protocol for
glasses, with the learning rate as temperature and the held-out loss as volume. The two losses separate again and nearly
reconverge over hundreds of steps. This repository contains the scripts behind every run, analysis, table and figure of
the manuscript, the dated analysis plan, and the evaluation data underlying the reported statistics.

## Contents

| path | content |
|---|---|
| `PREREG.md` | analysis plan for the withheld protocols and the interventions, with its dated addenda |
| `code/` | training, matching and analysis scripts, the exactly solvable model, the run chains (`run_*.sh`) and the figure scripts (`figs/`); [`code/README.md`](code/README.md) describes each script, and each script states its usage in its header |
| `results/` | per-run evaluation logs and the analysis outputs (below) |
| `figure_data/` | the data behind the figure panels, as extracted by `code/figs/fig*_data.py` |
| `tables/` | Supporting Information Tables S2–S7 as generated by `code/make_tables.sh` |

For every run `<run>`, `results/` holds `<run>_eval.tsv` (held-out losses on sets A and B, weight norms, learning rate),
`<run>_train.tsv` (minibatch loss), `<run>_meta.json` (protocol phases and match step) and `<run>_detail.npz`
(per-sequence losses at every evaluation, used by the block bootstrap). The `k_*.json` files are the analysis outputs,
`k_peaklaw_status.json` gives the status of every planned withheld run, the `*_final.txt` files are the reports from
which the numbers in the text are taken, and `data_sha256.txt` lists the SHA-256 checksum of every data file used.

## Data

The training data are public and are not redistributed here. Their versions and splits are given in the Supporting
Information (Section S6).

| data set | source | scripts |
|---|---|---|
| web text | GPT-2 token shards of FineWeb-10B, [`kjj0/fineweb10B-gpt2`](https://huggingface.co/datasets/kjj0/fineweb10B-gpt2) | `code/dl_fineweb.sh` |
| Python code | [`codeparrot/codeparrot-clean`](https://huggingface.co/datasets/codeparrot/codeparrot-clean) | `code/dl_domains.sh`, `code/prep_domains.py` |
| PubMed abstracts | chunk files pubmed23n0001–0060 of [`MedRAG/pubmed`](https://huggingface.co/datasets/MedRAG/pubmed) | `code/dl_domains.sh`, `code/prep_domains.py` |
| MovieLens-1M | [GroupLens](https://grouplens.org/datasets/movielens/1m/) (`ml-1m.zip`) | `code/kov_small.py` |
| CIFAR-10 | parquet release [`uoft-cs/cifar10`](https://huggingface.co/datasets/uoft-cs/cifar10) | `code/kov_small.py` |

## Requirements

Python 3.11 with PyTorch 2.6 (CUDA 12.4), NumPy, SciPy, pandas, pyarrow, matplotlib, tiktoken and Pillow. The versions
used are pinned in `requirements.txt`. All runs were made on one NVIDIA RTX A6000 (48 GB).

## Reproducing

The scripts were run on one server with the directory layout `/home/soso/advsci/{code,data,results,ckpt,logs}/kov` and
the interpreter `/home/soso/advsci/mlip/bin/python`. The shell scripts set these paths in their first lines; the Python
scripts take their inputs as arguments.

1. Data: `code/dl_fineweb.sh` and `code/dl_domains.sh` download and tokenize the language data.
2. Training: the run chains `code/run_*.sh`, starting with the pilot `code/run_k1.sh`. `code/README.md` lists what each
   chain runs and the order in which the chains were run.
3. Analyses: the `code/k_*.py` scripts, as called by the analysis chains (`run_an2b.sh`, `run_anal_ann.sh`,
   `run_an3b.sh`, `run_anal_rst2.sh`, `run_linfinal.sh`). `code/k_text_numbers.py` prints the numbers quoted in the text.
4. Tables and figures: `code/make_tables.sh` and `code/figs/render_all.sh` read only the files in `results/`, so they
   rebuild the tables and figures without retraining.
